# Experiment 20 – Create a GitHub Repository and Implement Version Control

## Aim

To create a GitHub repository and implement version control by using branches, pull requests, merge conflict resolution, and workflow documentation for collaborative software development.

---

## Problem Statement

Version control is an essential practice in software engineering that enables multiple developers to collaborate efficiently on a project. GitHub provides a distributed version control system using Git, allowing developers to work on separate branches, review code through pull requests, resolve merge conflicts, and maintain a complete history of project changes.

In this experiment, create a GitHub repository for a team project, implement branch-based development, merge changes through pull requests after code reviews, resolve merge conflicts if any, document the workflow using a README file, and submit the repository link.

---

## Objectives

- Understand Git and GitHub version control.
- Create and manage a GitHub repository.
- Create feature branches for different modules.
- Perform code reviews using Pull Requests.
- Resolve merge conflicts during branch merging.
- Document the project workflow using a README file.
- Collaborate effectively using GitHub.

---

## Requirements

Perform the following tasks:

1. Create a new GitHub repository for the team project.
2. Clone the repository to the local machine.
3. Create separate branches for individual modules or features.
4. Develop features independently in their respective branches.
5. Commit and push the changes to GitHub.
6. Create Pull Requests for merging feature branches into the main branch.
7. Review the Pull Requests and provide feedback.
8. Resolve merge conflicts, if any, during the merge process.
9. Merge the approved Pull Requests into the main branch.
10. Document the complete Git workflow in the `README.md` file.
11. Submit the GitHub repository link.

---

## Tools Required

## Files Required

- Project Documentation (Optional)

## Deliverables

---

## Expected Outcome

A GitHub repository is successfully created with proper version control practices, including branch management, pull requests, conflict resolution, and workflow documentation. The repository demonstrates effective collaboration and software version management using Git and GitHub.
